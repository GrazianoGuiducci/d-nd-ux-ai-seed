# Adaptive Semantic Surface Reference

This directory contains project evidence and machine-readable material for the candidate documented in `docs/ADAPTIVE_SEMANTIC_SURFACE.md`.

## Read Order

1. `../../docs/ADAPTIVE_SEMANTIC_SURFACE.md` — generic behavior and design contract.
2. `MAIOS_PROFILE.md` — project-specific adoption profile and Codex handoff.

## Boundary

The SVG is a visual blueprint, not a production page and not the current public truth of MAIOS. The target repository must be inspected at implementation time. Preserve current claims, state labels, accessibility behavior, routes, SEO and deployment boundaries.
