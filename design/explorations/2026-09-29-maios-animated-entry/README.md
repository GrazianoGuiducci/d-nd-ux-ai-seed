## Purpose

Explore a more distinctive first encounter for MAIOS that can later become either:

1. a bounded candidate for the `maios.it` Home entry; or
2. a focused landing for MAIOS products.

This space is deliberately upstream of production. It exists to form and test the visual/motion relation before any `maios_it` source change is selected.

## Present source relation

The exploration composes:

- the current MAIOS chromatic field and brand profile;
- the current `maios.it` Home as public-surface evidence;
- the D-ND Design Kernel methods for perceptual composition, cognitive motion, relational colour and web quality;
- Editoriali when public wording becomes consequential;
- operator-supplied visual references from 2026-09-29, including a GPT-generated layered-horizon image and current MAIOS screenshots.

The operator-supplied raster files are not committed in this first scaffold. Their role is recorded in `ASSET_MAP.md`.

## Working hypothesis

The useful relation in the supplied horizon image is not "mountains as the MAIOS brand".

It is:

```text
dense layered field
+ visible horizon
+ one warm attractor
+ controlled depth
+ sparse precise language
-> complexity becomes navigable rather than visually neutral
```

A candidate MAIOS expression can therefore use a **layered living field**: depth, interval and motion make the field perceptible, while exact labels, product names, controls and destinations remain editable HTML/SVG.

The visual field must not imply mechanisms, synchronisation, state or authority that the source does not establish.

## Initial medium decision

Preferred first prototype:

```text
semantic HTML
+ authored SVG / CSS shapes
+ CSS transforms / perspective
+ small requestAnimationFrame pointer/scroll controller
+ IntersectionObserver for entry/exit economy
+ progressive View Transition enhancement when useful
+ static/reduced-motion equivalent
```

Three.js/WebGL remains a bounded spike, not the baseline. It becomes justified only if viewpoint/depth materially improves the encounter beyond layered 2D/2.5D composition.

CSS scroll-driven animation is not a production dependency for the first prototype because current browser support remains limited; it can be tested behind feature detection without becoming the only motion path.

## Candidate visual event

A first concept to prototype:

```text
quiet MAIOS field
-> layered horizon responds subtly to pointer / device orientation where appropriate
-> scroll or explicit exploration reveals latent vectors / paths
-> the warm horizon object becomes a transition anchor
-> the field resolves into concrete MAIOS entry choices
-> exact product/action layer remains ordinary DOM
```

Motion carries orientation and depth, not perpetual decoration.

Possible visual material:

- current air/substrate/ground/path palette as the base field;
- dark blue-green ink for exact information;
- MAIOS green as action/identity accent;
- warm path/sun as a controlled attractor;
- violet only when a real focus state needs it;
- horizon layers rebuilt as authored SVG/CSS or a newly generated original asset rather than treating the small reference image as a production master.

## Product-truth boundary

Do not bake volatile release numbers, package state or moving product claims into the visual background.

The prototype may use stable product/route slots, but exact product truth must be reacquired from its owner before a public candidate is formed.

## Exit paths

After an observed prototype:

```text
if the relation strengthens the canonical Home:
  -> MAIOS Public System Projection
  -> Editoriali / public copy owner
  -> MAIOS Site System Modification
  -> bounded maios_it candidate branch
  -> proof
  -> separate publication decision

if the relation works better as a focused adoption/product landing:
  -> form the landing's exact public job
  -> acquire product owners
  -> create a separate bounded public-surface candidate

if motion/depth adds spectacle but not meaning:
  -> keep the brand learning
  -> discard the mechanism
```

No production implementation is authorized by this exploration.
