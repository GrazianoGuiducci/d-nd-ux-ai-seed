# Source and owner reconciliation

Design source version: 0.1.0 · 23 September 2026.

## Formation and delivery are different

The kernel was formed by exercising source-preserving competence formation,
RepoKernel-native synthesis/transfer and domain knowledge in one current receiver.
The deterministic RepoKernel compiler was not executed: this task needed a living
domain method, not a generated `.repokernel/` tree. Formatting skill files is not
the competence's generative method.

The source body is independently usable. Private source kernels, personal
workspaces, contact records, commercial state and credentials are not included.
External domain roles can be supplied by the receiving environment; a private
repository link is not an indispensable public runtime dependency.
